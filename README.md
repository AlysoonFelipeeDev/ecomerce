# 🛒 Shop Product Page

Página de e-commerce com catálogo de produtos e carrinho de compras, desenvolvida em 1 dia como parte de um portfólio de projetos rápidos que cobrem diferentes setores de negócio.

---

## ⚙️ Funcionalidades

- Listagem de produtos consumindo a [DummyJSON API](https://dummyjson.com/)
- Adicionar produto ao carrinho
- Remover produto do carrinho
- Aumentar e diminuir quantidade de cada item
- Cálculo do total do carrinho em tempo real
- Contador de itens no header
- Estado de loading com spinner animado
- Tratamento de erro na requisição

## 🏁 Como rodar localmente

**Pré-requisito:** Node.js instalado

```bash
# Clone o repositório
git clone https://github.com/AlysoonFelipeeDev/ecomerce

# Entre na pasta
cd ecomerce/shop-product-page

# Instale as dependências
npm install

# Rode o projeto
npm run dev
```
